## Изменения

- Добавлен HTTP CONNECT relay для TCP и WebSocket, включая настройку адреса в desktop UI.
- Добавлена поддержка `HTTPS_PROXY` / `https_proxy` и `NO_PROXY`; явная настройка relay имеет приоритет. Для прокси из окружения поддерживается Basic-авторизация.
- Добавлен консольный `tg-proxy-service` без CGO с общим конфигом desktop-приложения и корректной остановкой по сигналу.
- Добавлены пользовательский systemd-сервис, установка через `make install-user-service` и сохранение proxy-окружения в файл с правами `0600`.
- Исправлен автозапуск Windows: обработка путей с пробелами и автоматический старт прокси с сохранённой конфигурацией.
- WebSocket теперь пробуется и для DC, отсутствующих в пользовательском `DCMap`; при ошибке сохраняется переход на TCP.
- Исправлена остановка активных TCP/WebSocket-соединений при завершении сервиса.
- Обновлены зависимости Go и Android CI; версия приложения обновлена до 1.0.1.

## Загрузка

`tg-fyne-proxy-windows-amd64.exe` — desktop-приложение для Windows x64.

Консольный Linux-сервис можно собрать из исходников командой `make build-service`, затем установить через `make install-user-service`.
